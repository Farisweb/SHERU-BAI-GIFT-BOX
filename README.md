## 🌟 Key Features

1. **Brand Storytelling**:
   - Emotional homepage narrative introducing the gifting philosophy: *"A Small Gift Can Create a Big Smile. ❤️"*
   - White Lion royal crest and wax seal visuals.

2. **Streamlined Order System**:
   - One-click **BUY NOW** on each product card.
   - Dual-mode selection: **Self Purchase** vs **Send as a Gift**.
   - Sender & recipient contact capture.
   - Complete Pan-India delivery address with instant 6-digit PIN code serviceability validation across all 28 states & UTs.
   - **Interactive Live Greeting Card Preview**: Real-time rendering of personal gift messages with custom typography and Sheru Bai wax seal.

3. **Secure Multi-Method Payment Gateway**:
   - **UPI**: Instant QR code generator, quick app links (PhonePe, GPay, Paytm, BHIM, CRED), and UPI ID input.
   - **Credit / Debit Cards**: Visa, MasterCard, RuPay with real-time card spacing, expiry, and CVV protection.
   - **Net Banking**: Instant bank routing for top Indian banks (HDFC, SBI, ICICI, Axis, Kotak).
   - Instant Order ID generation (e.g. `SB-491208`) with 256-bit SSL encryption reassurance.

4. **Celebration & Order Confirmation**:
   - Golden and burgundy confetti celebration on payment success.
   - Full order breakdown and delivery timeline estimate.
   - **Print / Download Invoice** with clean receipt styling.

5. **Live Order Tracking**:
   - Lookup by **Order ID** or **Mobile Number**.
   - 5-step milestone delivery stepper:
     1. *Order Confirmed*
     2. *Handcrafted & Packed with Love*
     3. *Dispatched via Air Express Courier*
     4. *Out for Delivery*
     5. *Delivered & Smile Created!*
   - Pre-loaded with demonstration order (`SB-882194`) and local storage persistence.

6. **Footer & Legal Policies**:
   - Complete modals for **About Us**, **Contact Us**, **Privacy Policy**, **Refund & Cancellation Policy**, **Terms & Conditions**, and **Shipping Policy**.
   - Direct Instagram ([@sheru_baaai](https://www.instagram.com/sheru_baaai?vrfl=dHVkOGIxdG10Yjhk)) and Telegram ([@sherubaai](https://t.me/sherubaai)) links.
   - Reassurance of **zero hidden fees, no subscriptions, and no lottery models**.

## 🚀 Running the Project Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Development
```bash
npm run dev
# or
pnpm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```
Generates production-optimized assets in `dist/`.

### Preview Build
```bash
npm run preview
```
